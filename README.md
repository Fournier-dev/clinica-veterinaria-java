# Clínica Veterinária - Java

Sistema desktop desenvolvido em Java utilizando Programação Orientada a Objetos e Swing.

## Funcionalidades

* Cadastro de Tutores
* Busca de Tutores
* Cadastro de Animais
* Busca de Animais
* Cadastro de Consultas
* Cadastro de Serviços
* Relatório Geral
* Teste de Sons dos Animais

## Conceitos de POO Utilizados

* Encapsulamento
* Herança
* Polimorfismo
* Sobrescrita de Métodos
* Sobrecarga de Métodos
* Coleções (ArrayList e HashSet)

## Tecnologias

* Java
* Swing
* IntelliJ IDEA

## Estrutura do Projeto

* model
* service
